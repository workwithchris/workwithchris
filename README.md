## Recent Work

3D free-roam world built from OpenStreetMap and elevation data in Godot. Working on drivable mechanics and world interaction.

**[Nepali Utils Core](https://github.com/packages-by-chris/nepali-utils-core)**  
Framework-agnostic TypeScript library for Bikram Sambat date operations, number conversion, calendar utilities, location data, and more.  
→ TypeScript

**[Date Picker BS](https://github.com/packages-by-chris/date-picker-bs)**  
Customizable Bikram Sambat (Nepali) date picker and calendar with Radix UI and Tailwind CSS.  
→ React, TypeScript
